# 🛒 Sistema de Gestión de Supermercado

Proyecto desarrollado en Java aplicando Programación Orientada a Objetos.

## 🚀 Tecnologías utilizadas

- Java JDK 26
- IntelliJ IDEA
- Git
- GitHub

## 📌 Funcionalidades actuales

- Registro de productos.
- Mostrar información de productos.
- Control de stock.
- Venta de productos con validación de inventario.

## 📚 Aprendizajes aplicados

- Clases y objetos.
- Atributos y métodos.
- Encapsulación (próximamente).
- Control de versiones con Git.

## 🔮 Próximas mejoras

- Registro de clientes.
- Registro de empleados.
- Historial de ventas.
- Menú interactivo.
- Base de datos.
