# 🛒 Sistema de Gestión de Supermercado

Proyecto desarrollado en **Java** aplicando conceptos de **Programación Orientada a Objetos (POO)**.

El proyecto se está construyendo paso a paso, aplicando buenas prácticas de programación, validaciones, control de versiones y posteriormente conexión con base de datos y frontend.

## 🚀 Tecnologías utilizadas

* Java JDK 26
* IntelliJ IDEA
* Git
* GitHub

## 📌 Funcionalidades actuales

* Registro y creación de productos.
* Mostrar información de productos.
* Control de stock.
* Venta de productos con validación de inventario.
* Agregar stock.
* Validación de precios.
* Validación de stock.
* Manejo de excepciones con `IllegalArgumentException`.

## 📚 Aprendizajes aplicados

* Clases y objetos.
* Atributos y métodos.
* Encapsulación.
* Modificadores de acceso (`private`).
* Getters y setters.
* Constructores.
* Validación de datos.
* Manejo de excepciones.
* Reutilización de código y refactorización.
* Control de versiones con Git y GitHub.
